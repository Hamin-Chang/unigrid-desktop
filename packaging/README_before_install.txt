UNIGRID — 설치하기 전에

■ 무엇이 더 필요한가
  계산을 하려면 MATLAB Runtime R2024b 가 있어야 합니다.
  ※ 판이 정확히 R2024b 여야 합니다. 다른 판으로는 계산이 안 됩니다.
  없어도 앱은 설치되고 켜집니다 — 그때 어디서 받아 어디에 까는지 알려 줍니다.

■ 설치하다 경고가 뜨면
  "Windows에서 PC를 보호했습니다" 가 뜨면
  [추가 정보] 를 누른 뒤 [실행] 을 누르십시오.

■ 어디에 깔리나
  기본은 사용자 폴더입니다. 관리자 권한이 없어도 깔 수 있습니다.
