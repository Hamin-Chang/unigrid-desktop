# UNIGRID Desktop

AC/DC 조류계산 도구 **UNIGRID**의 데스크톱 앱 (PySide6/Qt).
계산은 MATLAB에서 컴파일한 엔진이 하고, 이 저장소는 **화면과 그 주변**을 담는다.

목표는 두 가지다 — **GitHub 공개 배포**, 그리고 **PSS/E의 조류해석 기능을 대체**하는 것.

## 이 저장소가 무엇이 아닌가

- **솔버(MATLAB) 원본이 아니다.** 그것은
  `…/Phase A_Balance/newest/v14/` 에 있고, 여기에는 **컴파일된 엔진만** 들어온다(`engine/`).
- **파이썬 라이브러리 `acdc_powerflow` 가 아니다.** 그것은 따로 공개돼 있고 남이 *라이브러리로* 쓴다.
  이 저장소는 **앱**이다 — 대상이 다르다.

## 폴더

| 폴더 | 무엇 | git |
|---|---|---|
| `src/` | **실행되는 코드만.** 임시·습작·캡처를 섞지 않는다 | 올림 |
| `engine/` | 컴파일된 계산 엔진 — **한 자리에만 둔다** | 올림 |
| `cases/` | 검증용 케이스 엑셀 | 올림 |
| `tests/` | **회귀를 한 명령으로** 돌리는 것 | 올림 |
| `docs/` | README·매뉴얼 | 올림 |
| `scratch/` | 임시 스크립트 | 안 올림 |
| `shots/` | 화면 캡처 | 안 올림 |
| `_backup/` | 엔진 옛 판 | 안 올림 |

엔진 폴더 모양은 **MATLAB이 만들어 주는 그대로**다 — 빌드 산출물의
`for_testing/unigrid_app_mac/` 폴더를 통째로 `engine/` 안에 넣으면 맞는다.
그 안에 `__init__.py` 와 `.ctf` 가 같이 있어야 하고, **폴더 이름이 곧 패키지 이름**이라
바꾸면 불러오기가 깨진다.

```
engine/unigrid_app_mac/__init__.py
engine/unigrid_app_mac/unigrid_app_mac.ctf
```

**`.py` 백업 파일을 손으로 만들지 않는다** — git이 대신한다.
`*_backup_<날짜>.py` 는 이력을 두 벌로 만들 뿐이다.
⚠️ **엔진 `.ctf` 만 예외** — 크고 git에 안 올리는 판이 생기므로 `_backup/<날짜>/` 에 둔다.

## 설계 문서

이 앱을 왜 이렇게 만드는지는 **PDR**(예비 설계 검토)에 있다:

`…/Phase A_Balance/newest/v14/UNIGRID_v2/PDR.md`

7장 구성 — 배경 / 뼈대에서 얻은 것 / 요구사항 / 예비 설계 / 위험과 미결 / 검증 계획 / 단계 계획.
**무엇을 정했고 왜 그렇게 정했는지가 거기 있다.** 같은 논의를 반복하지 않으려고 만든 문서다.

## 회귀 — 한 명령으로

```
./tests/regress.sh              # 견주기
./tests/regress.sh --save       # 지금 결과를 기준으로 삼기
./tests/regress.sh --only 14    # 이름에 그 글자가 든 케이스만
```

`cases/` 의 케이스 **11개**를 풀어 전압·조류·부하율·손실·발전기 한계·수렴 정보를
`tests/baseline/` 에 저장해 둔 값과 견준다. 다르면 **무엇이 얼마나** 달라졌는지 찍는다. 약 9초.

**통과 기준**: 차이 **0.00e+00**. 달라졌으면 **왜 달라졌는지 한 줄로 댈 수 있어야** 한다 — 못 대면 통과가 아니다.
의도한 변경이면 `--save` 로 기준을 다시 잡고 **무엇을 왜 바꿨는지 커밋 메시지에 남긴다**.

⚠️ 큰 계통(`case1888rte`·`case6495rte`·`25k`)은 여기 없다. 느려서 매번 돌리기엔 무겁고,
쓰임도 다르다 — **계통도가 몇 버스까지 버티나**를 재는 용도라 3단계에서 따로 쓴다.


## 두 대의 맥에서 쓸 때

이 폴더는 iCloud 동기화 대상(바탕화면) 안에 있다. **한 번에 한 대에서만** 작업한다 —
양쪽에서 동시에 고치면 iCloud가 `.git` 안에 충돌 사본을 만들 수 있다.
**진짜 백업은 GitHub**이다. iCloud는 백업이 아니라 동기화다.
