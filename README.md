# UNIGRID Desktop

**AC/DC 조류계산 데스크톱 앱.**
화면은 파이썬(PySide6/Qt)이 그리고, 계산은 MATLAB 에서 컴파일한 엔진이 한다.

AC 계통, DC 계통, 그리고 **둘이 변환기로 이어진 AC/DC 혼합 계통**을 한 정식화로 푼다.
같은 알고리즘의 논문판은 별도 저장소
[**unigrid-acdc-powerflow**](https://github.com/Hamin-Chang/unigrid-acdc-powerflow) 에 라이브러리로 공개돼 있고,
**이 저장소는 그것을 사람이 눈으로 쓰는 앱**이다.

## 켜기

> ⚠️ **설치본은 아직 없다.** 지금은 파이썬을 직접 불러 켠다.
> 두 번 눌러 설치되는 판은 만드는 중이다(아래 「어디까지 왔나」 6단계).

### 있어야 하는 것

| | 무엇 | 비고 |
|---|---|---|
| 파이썬 | **3.12** | 엔진은 3.9~3.12 를 받지만 3.12 로 시험한다 |
| **MATLAB Runtime** | **R2024b (24.2)** | 무료다. 계산 엔진이 이것 위에서 돈다 |
| 파이썬 패키지 | `requirements.txt` | PySide6 **6.9.1** · numpy · pandas · openpyxl |

MATLAB 본체는 **필요 없다.** Runtime 만 있으면 된다.
Runtime 이 없으면 앱은 뜨되 **어디에 무엇을 깔아야 하는지 알려 주는 화면**을 띄운다.

### 맥

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python src/app.py
```

### 윈도우

```
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python src\app.py
```

엔진은 맥·윈도우 두 벌이 `engine/` 안에 이미 들어 있다. 앱이 켜질 때 **제 운영체제에 맞는 것을 고른다.**

## 폴더

| 폴더 | 무엇 | GitHub |
|---|---|---|
| `src/` | **실행되는 코드만.** 임시·습작·캡처를 섞지 않는다 | 올림 |
| `engine/` | 컴파일된 계산 엔진 (맥 · 윈도우) — **한 자리에만 둔다** | 올림 |
| `cases/` | 검증용 케이스 엑셀 **18개** | 올림 |
| `tests/` | **회귀를 한 명령으로** 돌리는 것 | 올림 |
| `shots/` | 화면 캡처 (작업용) | 안 올림 |

엔진 폴더 모양은 **MATLAB 이 만들어 주는 그대로**다 — 빌드 산출물의
`for_testing/unigrid_app_mac/` 을 통째로 `engine/` 안에 넣으면 맞는다.
**폴더 이름이 곧 패키지 이름**이라 바꾸면 불러오기가 깨진다.

```
engine/unigrid_app_mac/__init__.py
engine/unigrid_app_mac/unigrid_app_mac.ctf
engine/unigrid_app_win/__init__.py
engine/unigrid_app_win/unigrid_app_win.ctf
```

**`.py` 백업 파일을 손으로 만들지 않는다** — git 이 대신한다.
엔진 `.ctf` 옛 판만 예외로 저장소 밖에 따로 둔다(크고, 이력을 여기서 관리하지 않는다).

## 회귀 — 한 명령으로

```bash
./tests/regress.sh              # 견주기
./tests/regress.sh --save       # 지금 결과를 기준으로 삼기
./tests/regress.sh --only 14    # 이름에 그 글자가 든 케이스만
```

`cases/` 의 **18개**를 전부 풀어 전압·조류·부하율·손실·발전기 한계·수렴 정보를
`tests/baseline/` 의 값과 견준다. 다르면 **무엇이 얼마나** 달라졌는지 찍는다.

**통과 기준**: 차이 **0.00e+00**. 달라졌으면 **왜 달라졌는지 한 줄로 댈 수 있어야** 한다 — 못 대면 통과가 아니다.
의도한 변경이면 `--save` 로 기준을 다시 잡고 **무엇을 왜 바꿨는지 커밋 메시지에 남긴다**.

⚠️ 큰 계통(`case1888rte`·`case6495rte`·25,000버스)은 여기 없다. 느려서 매번 돌리기엔 무겁고,
쓰임도 다르다 — **계통도가 몇 버스까지 버티나**를 재는 용도다.

화면은 `tests/shot_*.py` 가 창을 띄우지 않고(offscreen) 그려서 확인한다.
